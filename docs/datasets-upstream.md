# Upstream Datasets

These are the **external** benchmarks and corpora MemGym wraps or draws on — as
distinct from the artifacts MemGym itself produces (those are in
[data.md](data.md)).

For the license of each upstream asset, see [licenses.md](licenses.md).

## Software Engineering Datasets

| Abbreviation | Paper Title | GitHub |
|---|---|---|
| **SWE-bench** | *SWE-bench: Can Language Models Resolve Real-World GitHub Issues?* (Jimenez et al., 2024) | https://github.com/princeton-nlp/SWE-bench |
| **SWE-bench Lite** | (subset of SWE-bench) | https://github.com/princeton-nlp/SWE-bench |
| **SWE-bench Verified** | (human-verified subset of SWE-bench) | https://github.com/princeton-nlp/SWE-bench |
| **SWE-Gym** | *SWE-Gym: Training Software Engineering Agents and Verifiers with Open Source* (Pan et al., 2025) | https://github.com/SWE-Gym/SWE-Gym |
| **SWE-smith** | *SWE-smith: Scaling Data for Software Engineering Agents* (Yang et al., 2025) | https://github.com/SWE-bench/SWE-smith |
